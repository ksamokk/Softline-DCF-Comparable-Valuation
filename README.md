# Softline Valuation | DCF & Comparable Companies Analysis

**Financial valuation project | Microsoft Excel**

[Русская версия](README_RU.md)

## Project Overview

This project estimates the **enterprise value (EV)** and **equity value** of **Softline** using two complementary valuation approaches: **Discounted Cash Flow (DCF)** and **comparable companies / trading multiples**. The objective is to develop a structured financial model, compare the resulting valuations, and interpret the differences between the methods.

The analysis is presented in an Excel workbook containing historical financial analysis, forecasts, cost of capital calculations, terminal value estimation, and a final valuation comparison.

## Project Objectives

- Estimate enterprise value and equity value using a DCF model.
- Perform an independent valuation using comparable-company multiples.
- Translate equity value into an implied value per share.
- Compare both valuation approaches and summarize the implied valuation range.

## Methodology & Work Performed

### 1. Historical Financial Analysis

Reviewed historical financial and operating performance to establish a foundation for the valuation assumptions and forecast.

### 2. Discounted Cash Flow (DCF)

- Developed forecasts of the financial drivers used to estimate **Free Cash Flow to the Firm (FCFF)**.
- Estimated the **Weighted Average Cost of Capital (WACC)**, incorporating the cost of equity and cost of debt.
- Calculated **terminal value** using the Gordon Growth approach.
- Discounted projected FCFF and terminal value to obtain **enterprise value** and derived **equity value** and the implied share price.

### 3. Comparable Companies Valuation

- Applied a market-based valuation approach using trading multiples, including **EV/Revenue, EV/EBITDA, EV/EBIT, and P/E**.
- Compared the resulting market-based estimate with the DCF valuation.

### 4. Valuation Comparison

Consolidated the outputs of both methods to evaluate the difference between intrinsic and market-based estimates.

## Key Valuation Results

| Metric | DCF valuation | Comparable valuation |
|---|---:|---:|
| **Enterprise Value** | **RUB 35.95 bn** | **RUB 57.69 bn** |
| **Equity Value** | **RUB 21.14 bn** | **RUB 41.37 bn** |
| **Implied value per share** | **RUB 52.86** | **RUB 103.42** |

**Reference market price used in the model:** RUB 79 per share.

**Implied valuation range:** **RUB 52.86–103.42 per share**, based on the two model outputs.

## Interpretation

The DCF estimate is below the reference market price, while the comparable-company estimate is above it. This illustrates how valuation conclusions can differ depending on the underlying methodology: DCF focuses on projected cash flows and the discount rate, whereas the comparable approach reflects valuation levels observed among peer companies.

The two estimates provide a range for discussion rather than a single definitive price target. The figures represent the outputs of the financial model and are not an investment recommendation.
